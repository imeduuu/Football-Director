# Contribuir

## Commits

Usa [Conventional Commits](https://www.conventionalcommits.org/):

```text
<tipo>(<ámbito>): <resumen en imperativo>
```

Tipos habituales: `feat`, `fix`, `refactor`, `test`, `docs`, `build` y `chore`.
El resumen debe ser breve y describir el cambio. Añade un cuerpo cuando ayude a
explicar el motivo o sus consecuencias.

Ejemplos:

```text
feat(core): add deterministic player selection
docs: document local development workflow
```

## Definición de hecho

Una tarea está hecha cuando:

- Los tests pertinentes están añadidos o actualizados y pasan.
- La documentación afectada está actualizada.
- Los cambios están registrados en un commit Conventional Commits.

El commit lo crea la persona responsable del repositorio.
